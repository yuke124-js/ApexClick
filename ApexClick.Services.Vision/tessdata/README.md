# Языковые данные Tesseract

Положите сюда файлы `*.traineddata` (например `eng.traineddata` или `rus.traineddata`) и
включите Copy to Output Directory, если данные должны попадать в сборку приложения.

Языковые пакеты весят десятки мегабайт каждый и не включены в репозиторий — выбор языка(ов)
для поставки решается на уровне конфигурации релиза, не кодом.
