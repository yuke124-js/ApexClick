# Дизайн-токены — ApexClick

Источник: визуальный стиль лаунчера Yukora Studio (Electron, `launcher/src/styles/global.css`),
на который ApexClick ставится как одна из карточек-приложений — весь каталог должен выглядеть
как единая платформа, а не набор разностильных программ.

Реализация в WPF: `ApexClick.Views/Styles/DesignTokens.xaml` + `ControlStyles.xaml`,
подключены в `App.xaml`.

## Метафора
Тот же приборный подход, что и раньше (точный инструмент, не типовой SaaS-дашборд), но
цветовое решение теперь буквально повторяет лаунчер: чистый чёрный фон, полупрозрачные тёмные
поверхности, единственный акцент — мягкое белое свечение на интерактивных элементах.

## Цвет

| Токен | Значение | Назначение |
|---|---|---|
| Graphite Ink | `#000000` | фон приложения (как `.app-shell` в лаунчере) |
| Slate Panel | `#0A0A0A` | панели, инспектор |
| Fog White | `#FFFFFF` | основной текст |
| Steel Grey | `#999999` | вторичный текст, подписи |
| Surface Idle | `#0AFFFFFF` (белый, ~4% альфа) | фон кнопок/карточек в покое |
| Surface Hover | `#1FFFFFFF` (белый, ~12% альфа) | фон кнопок/карточек при наведении/выборе |
| Glow Border | `#24FFFFFF` → `#80FFFFFF` при наведении | тонкая рамка + анимированное свечение (`DropShadowEffect`) |
| Pulse Line | `#FFFFFF` (полная непрозрачность) | сигнатурная пульс-линия записи — единственное место с ярким белым без прозрачности |
| Ember Red | `#FF4D4D` | зарезервирован строго за индикатором записи (REC) — не использовать больше нигде |

## Типографика
- UI/заголовки: **Segoe UI** (тот же системный шрифт, что и в лаунчере).
- Данные (координаты, тайминги, hex шаблона, лог событий): моноширинный — **Cascadia Code** /
  Consolas.
- Текстовый логотип (`BrandTextStyle`) — жирный, с мягким белым `DropShadowEffect`-свечением,
  как заголовок "YUKORA STUDIO" в шапке лаунчера.

## Анимация наведения (замена CSS `.glow-surface:hover`)
Кнопки/карточки не могут использовать CSS `box-shadow`/`transition`, поэтому WPF-эквивалент:
`Border.Effect = DropShadowEffect` с `BlurRadius`/`Opacity`, анимируемые через
`Storyboard` в `Trigger.EnterActions`/`ExitActions` на `IsMouseOver`. Одновременно анимируется
цвет фона/рамки (`ColorAnimation` на `Background.Color`/`BorderBrush.Color`).

**Важное техническое ограничение**: кисти внутри `ControlTemplate`/`Style.Setters`, на которых
планируется анимация `Color`, обязаны быть объявлены как *литеральные* `<SolidColorBrush
Color="{StaticResource ...}" />` элементы, а не как ссылка на готовый `{StaticResource
...Brush}`. Иначе WPF отдаёт один и тот же кэшированный объект-кисть всем элементам, и
анимация на одной кнопке дёргает цвет у всех остальных, использующих тот же стиль.

## Layout главного окна
`LauncherShellWindow` теперь безрамочное (`WindowStyle="None"` + `WindowChrome` с
`CaptionHeight="0"`), со своей шапкой: текстовый логотип "APEXCLICK" по центру, круглые
кнопки свернуть/закрыть справа — один в один как `.titlebar` в `launcher/src/components/
TitleBar.tsx`. Перетаскивание и сворачивание/закрытие реализованы вручную в
`LauncherShellWindow.xaml.cs`, системная рамка resize (`ResizeBorderThickness`) сохранена.

Остальные окна (`SettingsWindow`, `DebuggerWindow`, `PluginManagerWindow`, `NodeEditorWindow`
и т.д.) стандартный WindowStyle не меняли — фон/кнопки/шрифты у них уже подхватывают новые
токены автоматически через общие ресурсы, но собственной безрамочной шапки как у главного
окна у них пока нет. При желании привести и их к безрамочному виду — сделать по образцу
`LauncherShellWindow.xaml`.

## Сигнатурные элементы
1. **Реактивная сетка** (`ReactiveGridCanvas`) — уже забирает цвет через `TryFindResource
   ("SteelGreyBrush")`, поэтому автоматически стала серо-белой на чёрном фоне без правок кода.
2. **Пульс-линия записи** (`RecordingPulseLine`) — теперь использует отдельную яркую
   `PulseLineBrush` (сплошной белый), а не приглушённый `SignalPulseGradientBrush` (тот
   остался для фона выбранной пилюли функции — там нужна лёгкая подсветка, не яркая вспышка).

## Definition of Done для дизайна
1. Скриншот главного окна в 4 состояниях: покой, запись, воспроизведение, пауза.
2. Проверка, что чёрный фон + белое свечение выглядят единообразно с лаунчером (не
   расходятся по оттенку/интенсивности).
3. Отдельная проверка сигнатурных элементов — пульс-линия должна быть отчётливо видна на
   вспышке, а не сливаться с фоном.
